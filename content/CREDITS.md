# Capipimon Zeraora pack

The Zeraora assets come from **CobbleCats 1.6** by Raspix, published under the **MIT License** (https://modrinth.com/datapack/cobble-cats).
- Original model, textures, animations and code: Raspix
- 1.6 model improvements: Knights of the Round Bagel. Animations: samysay21. Code tweaks: Treynami. Support: Ndraey.

Changes for Cobblemon 1.8.x (Capipimon):
1. Only the Zeraora files were kept (model, animations, poser, resolver, textures, cry + sounds.json entry, species addition, spawns).
2. Poser: fixed a malformed quirk, `lick_quirk'), 20, 50, 1)` → `lick_quirk', 20, 50, 1)`.
3. Spawns: renamed `context` to `spawnablePositionType`, Cobblemon 1.8's key.

Install as both a resource pack and a datapack. Not yet tested in game.

# Cobblemon species assets

Pikachu's model, animations and texture (`pikachu.*`, `textures/entity/pikachu.png`) come from **Cobblemon** (https://gitlab.com/cable-mc/cobblemon), whose models are licensed **CC BY-NC 3.0 Unported** by the Cobblemon team (the `license` file in its model folder). Unchanged apart from file names.
